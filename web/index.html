Methodology / v3

每个数字，都有明确的边界。

统计对象
最近 30 天创建、目标分支为 master 的 PR，包含开启中、已合入、已关闭未合入。汇集截至快照截止时刻的全部门禁；每个 trigger 编号独立计数，重跑不会被同 SHA 去重。
E2E 起止
起点为 PR 创建、推送事件或重跑评论的时间；终点为 trigger 及全部门禁子任务的最晚结束时间。独立文档门禁、GitCode Actions 与通知回写任务不计入。并行任务按墙钟跨度计算，不累加。
成功与失败
仅在批次结束、下游集合已核验且全部子任务成功时标记成功。子任务失败或 trigger 异常标记失败；仍在执行标记执行中，关联或结果缺失标记数据不完整。取消记失败，并纳入从请求到门禁停止的 E2E，以反映开发者实际等待。
PR 代表批次
每个 PR 选择有效 E2E 最长的批次；并列时选择 trigger 编号较大者。成功、失败和取消均可入选；执行中、数据不完整和缺失请求起点的批次排除。E2E、x86、ARM、DT 全部取自同一个代表批次；切换任务耗时类型不重新选择批次。
平均与 P90
顶部与图表按 PR 代表值计算算术平均及 PERCENTILE.INC 线性插值 P90，每个 PR 对每项指标最多贡献一个样本。有效 PR 样本数为 1 时标记样本不足。趋势按 PR 创建日期分组；覆盖率为有有效代表批次的 PR 数 / 当前 PR 数。
缺失与筛选
没有有效代表批次的 PR 仍计入 PR 数，耗时显示“—”。代表批次缺少某类任务或该类任务关联不唯一时留空，不从其他批次补取。排队数据缺失不补零。PR 状态、搜索、完整性筛选仅改变 PR 集合，不改变代表批次。详情始终保留全部提交、重跑及子任务；批次结果分布仅作辅助信息。
跨仓汇总
九个代码仓直接汇聚每个 PR 的代表值，不平均各仓均值或 P90。仅汇总时间范围与本次索引一致、成功或部分成功采集的快照；部分采集明确标记，失败和过期数据不混入。跨仓状态筛选仅改变 PR 集合，空仓仍保留。
时间与快照
毫秒精度计算，网页统一以 Asia/Shanghai 显示。PR 状态是采集时读取的状态；看板为离线快照，不自动追踪变化。运行采集命令后点击“重新加载快照”。
